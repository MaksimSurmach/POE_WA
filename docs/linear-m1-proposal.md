# Proposed Linear reset: POE Worksmith — Market Intelligence

Prepared 2026-10-29. The Linear document write was interrupted and did not apply;
the connected project still has its original recipe-first description. This file
contains the concrete proposed update. The existing project, document and code
should remain recoverable.

## Project summary

Аналитика рынка Path of Exile для крафтера: какие предметы нужны билдам, сколько
просят за сопоставимые вещи и как меняются наблюдения во времени.

## Project goal

Помочь выбирать, что стоит исследовать и крафтить в выбранной лиге, по проверяемым
потребностям билдов и рыночным данным. Основной путь: источник билда → требования
к предмету → профиль цели → сопоставимые предложения → история → решение.

Первый milestone — рабочая UI для библиотеки источников, профилей предметов,
публичного сбора экономики, импорта rare-наблюдений и истории снимков. Прибыль
появится после отдельной модели себестоимости, вероятностей и цены реализации.

Сохраняются TypeScript, React, отдельный backend, PostgreSQL и пригодные
repository/queue/rate-limit механизмы. Новый контур отделяется от recipe_id.
Прежние 20 рецептов, Merchant-only top-10, общий TTL, порог публикации 95% и
14-дневная история больше не определяют новый M1.

## M1 — Crafter Market Intelligence MVP

Пользователь добавляет источник и билд, задаёт базу и нужные свойства предмета,
собирает разрешённые economy-данные или импортирует наблюдения сопоставимых
предложений и сравнивает снимки в UI. Лиги, патчи, валюты и учебные данные
разделены. Для каждой цены видны происхождение, дата и размер выборки.

### Acceptance

- Создание цели и импорт выполняются через UI без редактирования БД.
- Есть проверенный начальный корпус: ориентир 5 билдов / 10 профилей со ссылками
  и датой проверки. Это рабочий объём, а не доказательство охвата меты.
- Публичный economy-коллектор реально получает данные, кеширует и сохраняет их.
- Для хотя бы одного профиля доступны два достоверных наблюдения в разные
  моменты либо из проверенного исторического архива.
- Данные переживают перезапуск; повторный импорт не удваивает историю.
- Ошибка, пустая выборка, 429, отсутствие доступа и устаревшие данные различаются.
- BaseType не подменяет цену готового rare; исчезнувший лот не считается продажей.
- Синтетические примеры не участвуют в реальной аналитике.
- Пройдены PostgreSQL и UI end-to-end проверки. Текущий PR — часть M1 до этого.

## Data and access decisions

Для public economy poe.ninja не нужны пароль PoE и игровой API-ключ. Требуются
идентифицирующий User-Agent, backend cache и уважение ограничений источника.
Для rare-предметов используется явный импорт наблюдений. GGG Public Stash требует
уже одобренного OAuth-клиента с service:psapi; регистрация новых приложений при
проверке приостановлена. Internal Trade Search и Ninja Builds не считаются
поддерживаемыми источниками для нового серверного сборщика.

Для прошлой лиги нужен конкретный проверенный архив. Его наличие пока не
подтверждено. Сегодняшние цены не используются как исторические.

Предлагаемая целевая политика полного M1: raw 30 дней, агрегаты 12 месяцев,
настраиваемо. Она ещё не реализована; новые таблицы не очищаются старой политикой.
