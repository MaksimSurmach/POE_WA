# Independent source review disposition

An actual Claude Code read-only run completed against the original research
sources. The session, model, elapsed time and review digest are recorded in
`claude-review-receipt.json`; the unedited output is `claude-review.md`.
The reviewer assessed source acceptance and translation risks, not the new
runtime code or final schema-v3 recipe definitions.

| Finding                                                        | Disposition                                                                                                                                                                           |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| H1: RF observed support pair does not prove Fire Trap demand   | Accepted. Preserve only the measured related bundle; no socket, purchase or Fire Trap-specific demand claim.                                                                          |
| H2: Intermediate counts cannot become whole-chain expected use | Accepted. Missing complete expected-use evidence leaves expected cost and ROI unestimated. No historical stage numbers are promoted automatically.                                    |
| H3: Starting conditions differ from finished-item filters      | Accepted. Keep the two specifications separate in every authored recipe and mapping. This is a translation guardrail, not proof of an existing runtime defect.                        |
| M1/M2: Old asks and low-budget labels                          | Accepted with narrower wording. Old snapshots establish neither current margin nor lack of margin. Build progression stage is not a measured cost class.                              |
| M3/L1/L4: Conflicting historical summaries                     | Accepted. The audit README identifies the final source precedence and historical drift; original files remain unchanged.                                                              |
| M4: Single stochastic bow run                                  | Accepted as uncertainty. Its action counts do not establish exact expectations. The review's numerical ±35% uncertainty estimate was not independently reproduced and is not adopted. |
| M5: SRS alias scope                                            | Accepted. The source's optional +1/+2 family is broader than the canonical +2 recipe. No inherited Spectre statistics or universal build equivalence.                                 |
| L2: RF item-level expectation correction                       | Accepted as a dated calculator result for its exact input; it does not make a complete monetary estimate.                                                                             |
| L3: Data-backed steps versus executed steps                    | Accepted. Keep the TR exact-10 bench retry and bow socket/link qualification limits explicit.                                                                                         |

All integration guardrails were sent to the recipe author before final catalog
validation. Whether the final code and catalog satisfy them must be established
by their current review and staging checks. The source review is not a GitHub
approval, product release gate or profitable-crafting certificate.
