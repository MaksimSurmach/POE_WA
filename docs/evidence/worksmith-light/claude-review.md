# Независимая проверка Claude

17 ноября 2026. Реальный Claude Code 2.1.323, модель `claude-opus-5-5`, effort `xhigh`. Модель подтверждена метаданными CLI.

## Первый проход и спор

Claude прочитал исходники, diff, требования и шесть исходных скриншотов. Вердикт: нужны исправления. На исходном коммите `30636cb` семь дополнительных регрессионных проб воспроизвели ошибки; CI также выявил два нарушения мобильного каталога.

Приняты и исправлены:

- Ложное «модификатор отсутствует»: серверные `explicit-0` и ID требований несопоставимы. Теперь показаны исходный предмет и честная неизвестность соответствия, без автоматического вывода по тексту.
- Переполнение кнопок заголовка; цена объявления и действие первой строки на мобильном экране. Таблица сохраняет внутреннюю прокрутку, мобильная цена берётся из того же источника.
- Сбой/загрузка API методов больше не маскируются под отсутствие совместимых методов. Добавлен повторный запрос. Совместимость определяется валидированной подписью цели, без зависимости от наличия изображения базы.
- Старые ссылки `/factory?batch=:id` снова открывают партию, активная вкладка соответствует содержимому.
- Выбор предмета для бюджета сохраняет представление; избранное и скринер открывают вкладку «Предмет», откуда доступен рецепт.
- Источник гайдов явно зафиксирован; в общем каталоге фильтр работает.
- План хранит валюту, происхождение и доступную дату цены. Неизвестная валюта не подменяется chaos; обновление котировки не переименовывает единицу сохранённого числа. Рыночные цены обновляются явно, ручные цены сохраняются.
- Полный одновалютный план переносит сумму и происхождение в редактируемый плановый бюджет партии. Валюта фильтра не задаёт валюту операции. Черновик не создаёт событий учёта.
- Экспорт TSV работает без Clipboard API, содержит UTF-8 BOM и защищает текстовые ячейки от формул.
- Навигация показывает все пять разделов на телефоне. При несовпадении лиг цены скрыты, инструкции доступны.
- Фильтр рыночного состояния отделён от вкладки `view`; снимки в Git обновляются только явным флагом.

Оспорены и сняты два вывода Claude: превышение среднего не обязано иметь вероятность 50%; редактируемый плановый бюджет не искажает фактический учёт. Горизонтальная прокрутка таблицы разрешена спецификацией и сама по себе не является ошибкой. Простое удаление валюты из ключа черновика было отвергнуто: для этого цена должна сохранять собственную единицу.

## Повторные проходы и проверки

В третьем проходе Claude самостоятельно запустил разрешённый проверочный скрипт: Node 22.23.5, pnpm 11.8.0, web typecheck, **137 unit-тестов и 57 browser checks** прошли. Это 19 сценариев на трёх проектах; часть мобильных проб принудительно выставляет 390×844 и повторяется между проектами. Это не 57 независимых пользовательских сценариев.

Claude дополнительно обнаружил неоднозначный локатор старого теста сравнения методов и неверное происхождение нетронутой неизвестной цены. Исправлены оба: тест различает ссылку метода и материалов; нетронутая строка остаётся рыночной и получает появившуюся котировку при обновлении. Ручное происхождение устанавливается только действием пользователя, ручные цены сохраняются.

CI на Linux выявил отличие первого мобильного экрана от локального рендера. Сводка цен теперь раскрывается по запросу, действие имеет высоту 44 px, а регрессионный тест требует **полной** видимости действия. Дополнительно исправлена передача фактической валюты порога прибыли, четыре смешанные фразы и числовое выравнивание. Мобильные вкладки переносятся без скрытых пунктов.

Последняя локальная проверка: **140 web unit-тестов и 60 browser checks** (20 сценариев, три проекта), lint и typecheck. Старый DB-backed тест методов уточняет локатор и дополнительно проверяет ссылку материалов, сохраняя проверки ранжирования, прибыли и P50/P90.

Условие приёмки: успешный полный [CI в PR #112](https://github.com/MaksimSurmach/POE_WA/pull/112/checks), включая integration/backend e2e, collector browser suite и legacy factory/freshness/two-methods. Локальный suite их не заменяет. Текущий статус следует проверять по конкретному head PR.

Четвёртый независимый проход Claude: в проверенном объёме P1/P2 не осталось; приёмка desktop/mobile/крафтер/учёт/доступность условна до зелёного CI. Два оставшихся P3 затем исправлены: числовое выравнивание ограничено таблицей партий и не затрагивает JSON журнала; изменение котировки определяется по цене, валюте и дате, включая неизвестную дату.

Изменён старый мобильный тест: вместо внеэкранной ячейки проверяются видимость мобильной цены и совпадение её значения с исходной ячейкой. Проверка действия сохранена. Проверки форм, API и учёта не ослаблены.

## Реальные ограничения

- Закрытый прототип потребовал входа; визуальное совпадение с ним не проверено.
- Нет backend-оценки цены отдельного мода, канонического сопоставления модов объявления или парсера пользовательского предмета. Эти возможности показаны как недоступные.
- Ручной план и серверная модель риска имеют отдельные цены и цели; P50/P90 показаны на один предмет и не умножаются на размер партии.
- Избранное и черновики локальны. Детальная диагностика, часть старых подписей и авторские материалы остаются на английском. Фильтр партий ограничен загруженной страницей; это раскрыто в UI.
- Настройки не добавляют новых серверных параметров отображения. Сравнение методов даёт переход к материалам каждого метода, а не объединённую модель закупки.
- Браузерная проверка использует синтетические данные; реальная текущая прибыльность, продажи и полнота рынка ей не подтверждаются.
- Production не менялся, PR не слит.
